What this shows

Standard portfolio optimization (Markowitz mean-variance) takes a set of input parameters — expected returns, volatilities, correlations — and produces a single “optimal” allocation. But those parameters are estimated from historical data, with real uncertainty. This widget illustrates what happens when you propagate parameter uncertainty through the optimization.

Set the central value and uncertainty for each parameter. The widget runs many Monte Carlo draws — each draw samples a complete set of parameters from your specified distributions, computes the resulting optimal (tangency) portfolio, and adds a dot to the cloud. The cloud shows the range of “optimal” allocations consistent with your parameter uncertainty.

What to notice

Even modest parameter uncertainty often produces wide clouds in the allocation space. The optimization framework treats its inputs as exact and produces precise-looking answers — but those answers are highly sensitive to the inputs. The same data, with mild uncertainty acknowledged, supports a range of “optimal” portfolios that can look quite different.

This isn’t a flaw in the math — it’s an honest reflection of how much the answer depends on inputs that aren’t precisely known. Real-world parameter uncertainty is also non-normal, non-independent, and time-varying; this widget uses normal independent distributions for clarity, which probably understates the true uncertainty.
